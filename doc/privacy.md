# TechMeku プライバシーポリシー

最終更新：2026-11-04（ドラフト）

TechMeku（以下「本アプリ」）は、利用者の情報をできるだけ持たない設計にしています。

## 1. サーバーに保存する情報

ログインした場合に限り、次の情報を運営者のサーバー（Cloudflare）に保存します。

| 情報 | 内容 |
|---|---|
| ユーザー識別子 | Google のユーザー固有 ID を、運営者だけが知る鍵でハッシュ化した値。元の ID には戻せません |
| ニックネーム | 自動生成。利用者が変更できます |
| 投稿・コメント・いいね・通報 | 利用者が行った操作の内容と日時 |
| 新規登録時の IP アドレス | 複数アカウントの作成を防ぐため、ハッシュ化した値を当日分だけ保持します |

**メールアドレス・氏名・プロフィール画像は、サーバーにもアプリにも保存しません。ログにも出しません。**

## 2. 端末にだけ保存する情報

興味タグ、ストック（保存した記事）、いいね一覧、設定は利用者の端末にだけ保存し、サーバーには送りません。

## 3. 外部サイトへの通信

記事の取得のため、利用者の端末から Qiita・Zenn・note へ直接通信します。これらの通信には各サイトのプライバシーポリシーが適用されます。

## 4. 削除

- 投稿は公開期間が終わると自動で削除されます。
- アカウントを削除すると、投稿・コメント・いいねを直ちに削除します。利用停止の記録（ハッシュ化した識別子）だけは、再登録を防ぐために残ります。
- 端末の情報は、アプリの設定から削除するか、アプリをアンインストールすると消えます。
